# 7F Miner for Windows: test builds

Signed test builds of **7F Miner**, the Windows app that runs a 7fchain
**testnet** node, wallet and miner in one window. It runs on Windows 10 22H2
or later (64-bit).

It runs on testnet only: testnet coins have no money value.

7F Miner is in testing, and anyone can download it and help. To mine, you
need an invitation: apply at https://forms.gle/exb8WDioMGVV1sds6.

## What you need

- Your own testnet **API key**, from your invitation email. The app asks for
  it once, to get your mining certificate. Keep it to yourself. You can
  download and install while you wait for it.

## Download

Open [Releases](https://github.com/Seven-Fortunas/7f-miner-testers/releases),
pick the newest **7F Miner \<version\>** and download
`7F-Miner-<version>-setup.exe`. Ignore the "Source code" archives. Each
release lists the file's SHA256 so you can check your download.

## Test it

Work through the [test guide](docs/test-guide.md): download, signature,
install, first start, sync and mining, settings, restart, and uninstall.

## Report what you find

Email **Mateo** at [mateo@sevenfortunas.com](mailto:mateo@sevenfortunas.com)
with the 7F Miner version, your Windows version and antivirus, what you did,
what you expected and what happened, screenshots, and the log file (the
guide says how to save it).

Never send your 24 words, app password or API key, to anyone.
